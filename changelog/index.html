Changelog

Firmware and app releases

Firmware updates are free and go over Bluetooth from the companion app. Each package is signed and the key refuses downgrades. App releases are on GitHub.

IK-1 firmware

The app checks immurok.com/fw/manifest.json and offers the latest build. Devices on 1.6.0 or later update directly; older devices go through the 1.6.0 bridge build first, which the app handles on its own. How the pipeline verifies a package is described in How immurok verifies its own firmware.

1.7.10 5 September 2026

  • Fixes a bug where a full pairing store could erase the pairing of the host still in use.
  • Unpairing now disconnects cleanly before the device resets.
  • Fixes the fingerprint sensor stopping after back-to-back authorization requests.
  • Connection parameter requests now stop when the host rejects them.

1.7.0 9 August 2026

  • Dual-host: the key keeps two independent pairings and a dedicated switch finger moves it between two computers. How dual-host works.
  • BLE pairing and fingerprint reliability fixes.
