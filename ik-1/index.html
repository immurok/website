What one touch does

  • Screen unlock. Lock screen, touch, unlocked. On a Mac mini, an iMac, a closed MacBook, a Windows desktop or a Linux box.
  • sudo and admin prompts. A PAM module on macOS and Linux and a Credential Provider on Windows turn the password prompt into a fingerprint prompt.
  • SSH and Git signing. The key holds an ECDSA P-256 private key that never leaves the hardware. Push commits and open SSH sessions with a touch.
  • Password managers. Unlock 1Password, Bitwarden, LastPass or Proton Pass with a dedicated password stored on the key, separate from your login password.
  • TOTP codes. Keep two-factor seeds on the key instead of in an app on the computer.
  • AI coding agents. Wrap a privileged command in imk run --agent -- and the agent has to wait for your finger. How the gate works.
  • Two computers. Bind the key to a desk Mac and a work laptop. One dedicated finger switches between them.

Security in one paragraph

Fingerprint templates are stored and matched on the key. What crosses Bluetooth is an HMAC-signed “match succeeded” notification, never the fingerprint. Pairing is a direct ECDH P-256 exchange between the key and your computer. Firmware updates are signed with ECDSA and the key refuses downgrades. Opening the case of a paired key trips a tamper switch that wipes it. There is no account, no server and no telemetry. The security model and the firmware verification pipeline are written up in full.

Questions before you order

When will my pre-order ship?

The current batch ships in December 2026. We email you when it leaves the warehouse, with a tracking number. If the date moves we email you too, and you can cancel for a full refund at any point before shipping.

Do I need the app, and does it cost anything?

Yes, and no. The key talks to a free companion app on macOS, Windows or Linux, which handles pairing, fingerprint enrolment and the integrations. The apps are open source under Apache 2.0 and there is no subscription for anything.

Can one key be used on two computers?

Yes, on up to two, connected to one at a time. Each computer gets its own pairing. You enrol one finger as the switch finger, and touching it moves the key to the other machine, which reconnects on its own.

Does it charge over USB-C, and can it work wired?

It charges over USB-C, and only charges. The port carries no data. Everything, including pairing and fingerprint results, goes over Bluetooth LE, so your computer needs Bluetooth and the key needs no free port while you work.

Which countries do you ship to?

The countries in the Ship to list of the order panel. Pick yours there to see the shipping price and delivery estimate before checkout. If your country is not listed, we cannot deliver there yet.
